# Browser test plan

Black-box tests of the built app (`dist/index.html`, opened from `file://` in headless Chromium via Playwright).
Models: `docs/test-protocol/models/` (generated by `generate.mjs`). Defaults referenced below: thickness 4 mm,
kerf 0.15 mm, sheet 600 x 400 mm, margin 5, spacing 3, mode oversize, labels on, engrave next outline on, DXF only.
Every test starts in a fresh browser context (empty localStorage / IndexedDB) unless it says otherwise.
